# discord-i18n

Automated Discord client UI translations.

## Layout

| path | channel |
|---|---|
| `tr.json`, `en.json`, ... | stable (root) |
| `ptb/*.json` | public test build |
| `canary/*.json` | canary |

`en.json` is `en-US`. Every file is sorted by key. Files refresh automatically.

## Usage

```
https://raw.githubusercontent.com/Discord-I18n/discord-i18n/main/tr.json
https://raw.githubusercontent.com/Discord-I18n/discord-i18n/main/ptb/tr.json
https://raw.githubusercontent.com/Discord-I18n/discord-i18n/main/canary/tr.json
```

Replace `tr` with any locale below.
